# STRIDE Kiro workspace context

These steering files are **new documentation for future Kiro sessions**, prepared from the current merged source. Their presence is not evidence that Kiro used them to build earlier phases.

- [Product](steering/product.md): intended use and safety boundaries.
- [Technology](steering/tech.md): active stack and integration contracts.
- [Structure](steering/structure.md): repository map and ownership.

The historical .kiro files are available at [commit 45e8c095](https://github.com/adhyannsingal/stride/commit/45e8c095b8679b2feb4529d4bd17f60e4380af93). They explicitly described retrospective work and were later removed, so they are cited in [Kiro_Usage.md](../Kiro_Usage.md) instead of being presented as original execution specs. No hooks, MCP servers, credentials or custom agents are configured here.

Kiro's [official steering guide](https://kiro.dev/docs/steering/) documents this workspace location and the product/tech/structure convention. Verify source and Git state before following these files if the application changes.
